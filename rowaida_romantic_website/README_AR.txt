# Rowaida — A Little Garden of Love

## الملفات
- `index.html`: هيكل الموقع.
- `style.css`: التصميم والألوان والأنيميشن والتجاوب مع الموبايل.
- `script.js`: تفاعل الورود والرسائل والقائمة والموسيقى والجزيئات المتحركة.
- `assets/`: ضع هنا ملف الموسيقى الذي تملك حق استخدامه.

## تشغيل الموقع
1. فك ضغط الملف المضغوط.
2. افتح مجلد `rowaida_romantic_website`.
3. افتح `index.html` في المتصفح. يفضّل استخدام VS Code مع إضافة Live Server.
4. الموقع يحتاج الإنترنت لتحميل خطوط Google Fonts؛ بقية التأثيرات معمولة بـ CSS وJavaScript.

## إضافة الموسيقى
- أنشئ مجلدًا اسمه `assets` بجوار `index.html` إن لم يكن موجودًا.
- أضف ملف MP3 تملك حق استخدامه أو لديك إذن باستخدامه.
- سمِّ الملف `rowaida-song.mp3`.
- اضغط زر الموسيقى داخل الموقع. التشغيل يبدأ بعد ضغط المستخدم بسبب قيود المتصفحات.

## تعديل الرسائل
افتح `script.js` وابحث عن `const messages`. عدّل النصوص بين علامات الاقتباس فقط مع الحفاظ على الفواصل وعلامات التنصيص.

## نشر الموقع
يمكن رفع المجلد على Netlify أو GitHub Pages. لو استخدمت Netlify، اسحب المجلد الذي يحتوي `index.html` إلى صفحة النشر اليدوي.
